## Среда аудита

Python 3.10.8, существующий `venv` исходного проекта.
`requirements-audit.txt` — снимок установленных версий исследовательского
пайплайна и их зависимостей; notebook/Jupyter-пакеты туда не включены.
Свежая установка по этому снимку в ходе аудита не проверялась.
Численные значения могут незначительно отличаться на другой платформе/BLAS;
особенно ненадёжно воспроизводить прямое решение вырожденной системы.

`FactorAnalyzer` 0.5.1 при MINRES переставляет столбцы нагрузок и structure,
но не переставляет `phi_`. Поэтому аудит восстанавливает согласованную матрицу
корреляций факторов из `structure = loadings @ phi` посредством least squares.
Этот порядок проверяется отдельным тестом. Косоугольные доли дисперсии не
суммируются как доли независимых факторов.

## Пределы диагностик

PCA parallel analysis использует 500 независимых перестановок строк каждого
столбца, 95-й процентиль и seed 20261014. Он проверяет спектр корреляционной
матрицы и не заменяет parallel analysis для общих факторов EFA.
Перестановочный нуль не учитывает зависимости партий внутри стран и общую
модель-оценщика, поэтому его результаты описательные.

K-means сравнивается для k=2..15 с 50 инициализациями. Устойчивость оценивается
100 одиночными инициализациями и 100 подвыборками из 80% партий без возвращения.
ARI и Jaccard для подвыборок считаются только на общих объектах. Кластерные номера
между разными запусками не сопоставимы напрямую. Эти проверки фиксируют баллы
факторов; повторное измерение LLM и переобучение факторов в них не выполняется.

Проверка исключения стран переобучает трёхфакторный MINRES/varimax с
`use_smc=False` на оставшихся партиях и сопоставляет нагрузки по абсолютной
конгруэнтности Такера. Язык признаков, исходная модель и способ оценки фиксированы.
Это не независимая репликация.
