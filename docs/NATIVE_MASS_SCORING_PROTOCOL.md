# Последовательное оценивание корпуса без API

Решение пользователя от 18.10.2026: начать с 751 отобранного фрагмента,
затем проверять остальные подходящие фрагменты блоками по 500.
Словарь: утверждённые 38 независимых признаков, 42 участника.

Порядок фиксируется до оценивания. В первой части сначала идут участники
с небольшим количеством материалов; внутри участника порядок идентификаторов
не меняется. Остаток перемежается по участникам, чтобы частота сообщений
о президенте не определяла момент остановки. Исходные тексты и журнал
сопоставления идентификаторов остаются локальными.

Оценки выставляются при смысловом прочтении исходной цитаты и контекста
атрибуции здесь, в чате. Машинное описание, поисковое совпадение, должность
и частота публикаций сами по себе не дают численной оценки. Если просмотрен
только фрагмент, это явно отмечается; прочтение полной статьи не заявляется.
Повтор одного эпизода не является новым наблюдением. Отсутствие признака
в тексте не означает ноль. Сведения о третьих лицах, старые события,
протокольное участие и художественное изображение проверяются отдельно.

На каждом рубеже сохраняются все 1596 ячеек и изменения относительно
предыдущего рубежа, отдельно для датированных сведений и чувствительности
к неизвестному времени. Существенным считается появление или потеря
известного значения либо изменение не менее чем на 0,5 балла шкалы 0–5.
Число источников и подтверждений сохраняется отдельно от силы признака.

Ранняя остановка допустима после двух последовательных полных блоков
по 500 без существенных изменений, только после просмотра оставшихся
материалов редких участников (не более 10 подходящих фрагментов на человека).
Если это условие не выполнено, просмотр продолжается до исчерпания очереди.
Стабильность оценок не доказывает репрезентативность корпуса или истинность
политологических выводов. Незавершённые блоки не считаются стабильными.

Сравнение факторных решений проводится с прежними критериями допуска.
Неизвестные значения не заменяются нулями ради получения решения.
При недостаточном покрытии результатом проверки будет отказ в факторизации,
а не искусственная полная матрица. Затраты новых платных API-запросов: $0.
