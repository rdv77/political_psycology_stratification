Корпус материалов

Импортируйте выгрузку, проверьте документы и подготовьте обработку. Вызовы моделей запускаются отдельно.

1. Добавить локальную выгрузку

Файл читается локальным сервером. Импорт не вызывает API. Настройки выбранного исследования копируются; само исследование не меняется.

Новый корпус получает экономный режим: до 1500 токенов вокруг имён на публикацию и сокращённый справочник. После импорта настройки можно изменить.

2. Область исследования и модели

Копирование доступно для утверждённого списка объектов. Шкалы из другого исследования требуют отдельного утверждения для этого корпуса.

Объём передаваемого текста

Для контекста выбираются имена и утверждённые варианты их написания. Лимит общий для всех фрагментов одной публикации; в режиме полного текста он не применяется. Инструкции и ответ оплачиваются отдельно. Без локального токенизатора применяется более строгий лимит по байтам. Исходный текст сохраняется целиком.

Модели по этапам

Можно выбрать недорогую модель для отбора материалов и отдельную модель для извлечения и интерпретации. Ключи задаются на сервере.

Стоимость и расширенные настройки

Ставки в USD за миллион токенов. Для модели без известной цены укажите ставки перед запуском.

Черновик признаков

Проверьте определения и отдельно утвердите шкалы перед оцениванием. Балл описывает выраженность в одном эпизоде; число публикаций и повторов учитывается отдельно. Недостаток сведений остаётся неизвестным, а не нулём.
