# Сравнение размерностей на неизменных оценках

q2 — побайтовый снимок исходного анализа; q3/q4 — новые офлайн-модели при k=3. Каждый каталог содержит полные нагрузки, координаты, профили объектов и групп, все кандидаты k и параметры проекции. Исходные study.json/ratings.json и главный output не изменяются.

input_study.json и input_ratings.json — точные побайтовые снимки входов; их SHA256 записаны в scope.input_files. Повтор использует сохранённый study, поэтому добавленные позднее сведения отчёта не меняют input_sha256 модели. Изменение измерительных полей или оценок требует нового каталога сравнения.

q3/selected_k4 и q4/selected_k4 — содержательно выбранные варианты с четырьмя группами. Они используют те же нагрузки, стандартизацию и координаты; факторный анализ и оценивание объектов для изменения k не повторяются. Численная рекомендация q3 — k4, q4 — k3; выбор q4k4 сохранён как явная содержательная альтернатива.

comparison.json — машиночитаемый результат; *_all_objects.csv содержит все переходы, *_changed_objects.csv — только изменения после max-overlap выравнивания меток. Равенство номера фактора между q не подразумевает равенства смысла. Совпадение кластерных меток определяется отдельно в каждой паре сравнений. Результаты свободного выбора k — численные предложения, не окончательные содержательные решения.

Повтор: python -m scripts.compare_factor_models STUDY_JSON RATINGS_JSON BASELINE_OUTPUT --selected-k 3:4 --selected-k 4:4

Существующий снимок q2 защищён манифестом и не перезаписывается. Повторный расчёт заменяет численные q3/q4 и их стандартные описания; содержательные интерпретации следует применять отдельным этапом после расчёта.
