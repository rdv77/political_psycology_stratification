# Руанда: версия по исправленным источникам V2

Отдельная версия от 18 октября 2026 года. Предыдущее исследование сохранено в родительской папке.

- [Основной отчёт Markdown](report.md), [PDF](report.pdf), [HTML](report.html).
- [Презентация, 36 слайдов](slides.pptx).
- [Технический отчёт Markdown](technical/report.md), [PDF](technical/report.pdf), [HTML](technical/report.html).
- [Содержание презентации для воспроизводимой сборки](presentation_content.json).

В основной датированной матрице подтверждены 39 сочетаний «человек - признак» у 18 из 42 участников. Отдельный сценарий с неуточнёнными датами содержит 71 известную ячейку у 28 участников. Все остальные значения остаются неизвестными. Частота публикаций не определяет выраженность признака.

Оба сценария не проходят ранее установленные требования к достаточности измерений. Новые факторные оси, координаты и кластеры не вычислялись. Показатели прежних решений с 2, 3 и 4 факторами приведены для исторического сопоставления и относятся к другой матрице.

Диаграммы и таблицы презентации остаются редактируемыми. Отчёт содержит все 38 утверждённых признаков и справки обо всех 42 участниках. Содержательные темы отдельных эпизодов не называются статистическими факторами или кластерами.

Сборка работает локально с сохранёнными данными. Новых платных API-запросов нет.
