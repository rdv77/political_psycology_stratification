# Офлайн-пакет проверки оценивания Руанды

Пользователь выбрал продолжение без платных запросов; баланс API пока не пополнен. Платный запуск отложен (`execution_allowed=false` в манифесте пакета). Новые расходы — **$0**.

Подготовлено **60 единиц материала** для **35 участников** и **12 отдельных исключённых контролей**. Все **42 карточки** сохранены; оценок нет.

Сначала выбрана одна единица для каждого участника с пригодным материалом, начиная с самых редких. Остальные места заполняются для разнообразия языков, атрибуции, дат, буквальных повторов и упоминаний России. Не более трёх единиц на человека. Состав воспроизводим и зафиксирован контрольными суммами.

Язык публикации взят только из завершённых активных проверок релевантности. Это сохранённая модельная разметка, а не новая проверка языка цитаты. Конфликты и отсутствие разметки дают `unknown`; языковые подсказки выгрузки не используются. Упоминание России служит только поводом проверить фрагмент, не оценкой позиции.

Допустимость означает прохождение текущего входного фильтра; смысл, говорящий и связь с событием ещё подлежат проверке. В локальном пакете сохранён пустой шаблон такой проверки; все поля заключения остаются незаполненными.

Буквальная группа ещё не является независимым эпизодом. Перед оцениванием нужны проверка говорящего, времени, служебной роли и связи материалов с одним событием. Поэтому калибровочная и проверочная части пока не разделены. Неизвестные даты остаются неизвестными; все оценки — `not_scored/null`.

Исходные цитаты, идентификаторы фактов и документов остаются только в локальном закрытом пакете. Очередь, исходные квитанции, утверждённые данные и старые результаты не изменены. Для будущего платного пилота понадобятся отдельный лимит и пополнение API; прежний лимит $70 не расширяется. Пополнение баланса не запускает обработку автоматически.
