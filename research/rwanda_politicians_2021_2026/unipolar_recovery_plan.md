# Восстановление отдельных полюсов: архив предложений и план проверки

Это вспомогательный архив, **не новая матрица измерений**. Прежние отклонённые пары не стали принятыми оценками. Канонические `study.json`, `ratings.json`, досье и ответы провайдеров этим инструментом не изменяются.

В 137 сохранённых ответах и прежней матрице обнаружено 1629 численных предложений полюсов, включая повторы между исходной матрицей и её raw-ответами. После объединения по объекту, шкале и полюсу остаётся 880 позиций хотя бы с одним численным предложением; у 582 есть ненулевой кандидат, прошедший формальные проверки индексов, даты и происхождения снимка. Это **верхняя граница кандидатов до содержательного аудита**, а не число надёжных измерений. Нули не принимаются на основании молчания или отсутствия найденных материалов.

Файл `unipolar_recovery_counts.json` содержит покрытие всех 48 переменных кандидатами. Только продолжение действующего курса и защита репутации имеют по 26 кандидатов из 42; остальные не достигают этого порога даже до содержательной проверки. Нельзя по этим числам заключать, что факторы уже получены или какого-либо фактора нет.

`unipolar_recovery_inventory.json` сохраняет SHA256 каждого входа, факты с исходными индексами, исходное число, обоснование, модельный ответ и прежнее решение аудита. Для специальных тематических запросов локальные индексы сокращённого списка переведены в индексы полного досье тем же правилом отбора. Если имеется неизменяемый снимок `attempts/paired_difference_2026-10-15`, используется именно его матрица, чтобы новое независимое оценивание не подменяло исторические данные.

## Правила возможного восстановления

Каждый полюс проверяется отдельно. Сохранять можно только существовавшее число и только при прямом соответствии сохранённых эпизодов смыслу свойства. Подтверждённый полюс не требует известного противоположного. Пересмотр всей отвергнутой пары или автоматическое принятие любого ненулевого числа запрещены. Для нуля требуется прямое свидетельство невыраженности данного свойства. Значения выше 2 требуют повторяющихся самостоятельных эпизодов; несколько пересказов одного события не образуют повторяемость. Если завышенное число нельзя сохранить, оно остаётся unknown: этот инструмент не назначает вместо него новое число.

Исторические кандидаты пока архивируются без принятия: начат новый проход с независимыми полюсами и отдельными основаниями каждого свойства. Поэтому `unipolar_recovery_reviews.json` содержит пустой список решений и явный статус незавершённого пересмотра. Построение исторического предложения возможно только с `--recover-reviewed` после завершённого привязанного к снимку семантического аудита. Автоматического применения в каноническую матрицу у скрипта нет.

## Проверка нового прохода

Команда `python -m scripts.recover_rwanda_independent_poles --audit-fresh --start 14 --stop 28 --batch 2` создаёт отдельный пакет для средней трети выборки, по мере появления `evidence/independent-ratings-ID.json`. Пакет содержит определение свойства, исходное число, обоснование, точные выписки и SHA256 входов. Отсутствующие ещё объекты перечисляются отдельно. Структурные ошибки отделены от вопросов для содержательной проверки.

Проверяются границы чисел, unknown/null, объект досье, basis, индексы, соответствие URL индексам, период и допустимость тематических свидетельств. Предупреждения выделяют нули, сильные оценки без нескольких датированных событий, контекстные факты и объяснения через отсутствие данных. Предупреждение не является автоматическим решением; предметный аудит проверяет смысл, личную атрибуцию, различие намерения и реализации, а также независимость эпизодов.

После проверки трёх частей выборки допустимо исключить только неподтверждённые отдельные полюса, сохранив подтверждённые противоположные. Покрытие и пригодность для факторного анализа пересчитываются уже по проверенной новой матрице. Оставшиеся пропуски честно сохраняются; численный порог полноты не является основанием для назначения значений или повторных запросов до желаемого результата.
